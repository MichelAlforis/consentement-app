# Contenu Explicite (`ageGate: 'explicit'`)

**Accès :** 18+ ET Mode Explicite activé (isAdult && explicitMode)  
**Activation :** Toggle dans la Home + Paramètres, avec modale de confirmation  
**Persistance :** localStorage (`consentement-settings.explicitMode`)  
**Mis à jour :** 2026-04-22

---

## Philosophie éditoriale

Ce contenu décrit des actes sexuels réels sans métaphore ni euphémisme — fellation, cunnilingus, pénétration, positions sexuelles. Il s'adresse à des adultes consentants qui souhaitent explorer et verbaliser leur sexualité explicitement.

L'objectif reste celui de toute l'application : **créer de la communication et du consentement**. Même dans le registre le plus cru, chaque prompt est une invitation à la parole partagée, pas une injonction à l'acte.

**Registre :** Direct, cru, sans ambiguité, mais ancré dans le consentement et le désir mutuel.  
**Ce qu'on maintient même ici :** le respect, la co-construction, la possibilité du non.

---

## Modale de confirmation (UX)

Lorsque l'utilisateur active ce mode pour la première fois, une modale apparaît :

> **Contenu explicite**
>
> Ce mode débloque des contenus sexuellement explicites — fellation, cunnilingus, actes sexuels décrits sans ambiguité.
>
> Réservé aux adultes consentants. Assurez-vous d'être dans un environnement approprié.

Boutons : **Activer le mode explicite** / **Annuler**

La désactivation est immédiate, sans confirmation.

## Architecture technique

```
explicitMode: boolean   ←  useSettingsStore
                             ↓
  DiceGame    CardGame    GooseGame
  (filtre    (filtre      (getBoardActivities-
  useMemo)   useMemo)      ForFace + isExplicit)
```

**Règle de filtrage dans chaque jeu :**
```ts
if (p.ageGate === 'explicit') return isAdult && explicitMode;
```

**Toggle accessible depuis :**
- Home adulte (carte toggle pleine largeur, toujours visible)
- Paramètres (ligne avec pill toggle, visible seulement si isAdult)

**Reset :** `resetAllData()` remet `explicitMode: false`

## Lignes directrices éditoriales

Pour ajouter du contenu dans cette catégorie :

- **Thèmes autorisés :** fellation, cunnilingus, pénétration, positions sexuelles, sexe oral, description anatomique directe, orgasme
- **Langage :** direct, sans euphémisme, clinique si besoin mais jamais vulgaire au sens dégradant
- **Ancrage consentement obligatoire :** chaque prompt doit rester une invitation à la parole ou à l'acte *consenti et partagé* — jamais une injonction unilatérale
- **Ton :** assumé, adulte, sans honte — mais ancré dans le respect mutuel
- **Longueur :** même format que les autres niveaux — une phrase, action ou question concrète
- **Interdit même ici :** humiliation non-consentie, violence, contenu impliquant des mineurs, contenu dégradant sans consentement explicite dans le prompt
