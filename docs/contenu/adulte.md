# Contenu Adulte (`ageGate: 'adult'`)

**Accès :** 18+ uniquement (isAdult === true)  
**Filtrage :** Conditionné par le passage de l'AgeCheckScreen  
**Mis à jour :** 2026-04-22

---

## Philosophie éditoriale

Ce contenu aborde la vie intime, les désirs et la sexualité de façon suggérée, poétique ou allusive — sans jamais décrire d'actes sexuels de façon explicite. Il crée un espace de parole sur l'intimité, les fantasmes et les préférences, en invitant à la vulnérabilité sans franchir dans le cru.

**Registre :** Sensuel, introspectif, légèrement provocateur, métaphorique.  
**Ce qu'on évite :** Toute description anatomique directe, tout acte sexuel nommé, tout langage cru. On parle de désir sans montrer l'acte.

**Différence avec Explicite :** Le mode adulte parle *autour* de la sexualité. Le mode explicite la décrit *directement*.

## Lignes directrices éditoriales

Pour ajouter du contenu dans cette catégorie :

- **Thèmes autorisés :** désir, attirance, fantasme, sensualité, intimité physique, confiance érotique, corps, toucher
- **Langage :** allusion, métaphore, suggestion — jamais d'acte sexuel nommé directement
- **Exemples de langage OK :** "ce que vous aimeriez faire", "votre fantasme", "la façon dont il/elle vous touche", "quelque chose de nouveau"
- **Exemples de langage interdit ici (→ Mode Explicite) :** "fellation", "cunnilingus", "pénétration", "jouir", description anatomique
- **Contact physique :** massage, guidage de mains — dans un registre sensoriel non-explicite
- **Ton :** sensuel, vulnérable, courageux, sans vulgarité
